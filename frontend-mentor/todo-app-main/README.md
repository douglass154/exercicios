## 📖 Overview

A responsive **Todo App** that allows users to manage tasks with features like filtering, light/dark mode, and smooth UI interactions.  
The design and requirements were provided by Frontend Mentor, and the project was fully coded by me.

---

## ✨ Features

- ✅ Add new todos  
- ✅ Mark todos as completed  
- ✅ Delete todos  
- ✅ Filter by **All / Active / Completed**  
- ✅ Clear completed todos  
- ✅ Responsive design (desktop & mobile)  
- ✅ Light and Dark mode with theme toggle
- ✅ Drag and Drop  
- ✅ Custom styled scrollbars for better UX
